      Como interpretar o teste
      
    
        
  • O 307 preserva o POST, o corpo e os cabeçalhos. O preflight também ocorre na chamada direta entre origens.
    • 
        
  • set substitui a lista. merge acrescenta à lista existente. Um único set com Content-Type, X-Demo-Token também funciona.
    • 
        
  • Com text/plain e token, o navegador pede só x-demo-token. Com JSON sem token, pede só content-type.
    • 
        
  • O fetch informa uma falha genérica. A mensagem reconstruída aponta o cabeçalho ausente e usa redirected from para indicar a URL inicial.
